    {{NOTES}}

    How each point was checked

    Four independent references

    {{LEDE_METHOD}}

    US Census geocoder

    TIGER address-range interpolation on the layer’s address field, independent of OpenStreetMap. It places the point on the street centreline, so it confirms the block rather than the building.

    ArcGIS World Geocoder

    Rooftop-level PointAddress matches from Esri's commercial reference data. The strongest single check, and independent of both other sources.

    OpenStreetMap footprints

    Building and site outlines for {{N_FP}} of the {{N}} points, fetched through Overpass, used for a point-in-polygon test and a distance to the nearest edge.

    Reverse geocoding

    Each recorded coordinate was reverse-geocoded to name the feature standing there. This is what turns a distance into evidence you can check.
